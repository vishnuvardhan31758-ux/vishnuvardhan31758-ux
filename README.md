## 🚀 Featured Intelligence Projects

I build systems where AI isn't just a tool, but a core architectural component.

### 🌌 [OmniAI Workspace](https://github.com/vishnuvardhan31758-ux/OmniAI-Workspace)
**Multi-Model AI Orchestration Platform**
- Unified interface for Gemini, OpenAI, and Local LLMs.
- Advanced system monitoring and voice-command integration.
- Professional workspace for AI-driven productivity.

### 🌍 [SentientOS Core](https://github.com/vishnuvardhan31758-ux/SentientOS-Core)
**Autonomous Earth Operating System**
- Planet-scale multi-agent intelligence built on the Masumi Network.
- Four specialized intelligence divisions (EID, ENID, DTAD, HID).
- Integration of blockchain-based agent settlements and local NLP.

### 🏃 [FitQuest MindSprint](https://github.com/vishnuvardhan31758-ux/FitQuest-MindSprint)
**Gamified Fitness Ecosystem**
- Transforms physical activity into territorial conquest using H3 geospatial indexing.
- High-performance NestJS backend with Redis caching for real-time competition.
- Complex social engineering with team alliances and power-ups.
